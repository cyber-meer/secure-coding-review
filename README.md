# Secure Coding Review

A professional cybersecurity project focused on reviewing JavaScript web application code and identifying common security vulnerabilities.

## Features

- Secure coding review dashboard
- Vulnerability identification
- Severity classification
- Vulnerable vs secure code comparison
- Static security scanner
- Input validation checks
- Hardcoded secret detection
- Unsafe DOM manipulation detection
- Security recommendations
- Remediation plan
- Responsive professional UI

## Technologies

- HTML5
- CSS3
- JavaScript
- OWASP secure coding principles

## Security Findings

The project demonstrates common issues such as:

- Cross-Site Scripting (XSS) risks
- Hardcoded secrets
- Insufficient input validation
- Unsafe DOM manipulation
- Dangerous JavaScript functions
- Verbose error handling
