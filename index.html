Secure Implementation

function displayMessage(userInput) {

    const output = document.getElementById("output");

    // Safe text insertion
    output.textContent = userInput;

}

function processInput(input) {

    // Basic validation
    if (typeof input !== "string") {
        return "";
    }

    return input.trim();

}

Recommendations & Best Practices

Actions recommended to improve application security

01

Validate User Input

Validate input type, format, length and expected values before processing user-controlled data.

02

Avoid Unsafe DOM APIs

Prefer textContent or safe DOM APIs instead of directly inserting untrusted HTML.

03

Protect Secrets

Never hardcode passwords, API keys or private credentials inside publicly accessible client-side code.

04

Use Security Headers

Configure appropriate security headers such as Content Security Policy to reduce browser-based attacks.

05

Perform Regular Code Reviews

Combine manual inspection with automated static analysis tools throughout the development lifecycle.

06

Handle Errors Securely

Log detailed information internally while displaying generic messages to application users.
